# 🍵 Tea Brand Website

مرحبًا بكم في مشروع **Tea Brand Website**.

هذا المشروع هو مشروع جماعي يهدف إلى محاكاة بيئة العمل الحقيقية داخل فرق تطوير الواجهات الأمامية (Front-End).

سيعمل كل طالب على جزء محدد من الموقع باستخدام **HTML** و **CSS** فقط، ثم سيتم دمج جميع الأعمال في مشروع واحد باستخدام Git و GitHub.

# 🚀 Getting Started

قم بعمل Clone للمشروع

```bash
git clone repository-url
```

ثم ادخل إلى المجلد

```bash
cd Tea Brand WebSite
```

---

# 🌿 Create Your Branch

لا تعمل مباشرة على Branch الرئيسي develop.

أنشئ Branch جديد باسم المهمة الخاصة بك.

مثال:

```bash
git checkout develop

git pull origin develop

git checkout -b feature/navbar
```

---

# 💻 أثناء العمل

اعمل فقط على الجزء المكلف به.

لا تعدل ملفات أو أقسام الطلاب الآخرين.

إذا احتجت تعديلًا في جزء آخر أخبر المسؤول أولًا.
لاتنسى تحديث مشروعك اول بأول لتظمن عدم حدوث تعارضات او مشاكل .

---

# ✅ Commit Messages

استخدم رسائل Commit واضحة.

أمثلة:

```bash
git commit -m "feat: create hero section"

git commit -m "fix: footer spacing"

git commit -m "style: update buttons"
```

---

# ⬆ Push

بعد الانتهاء

```bash
git push origin feature/navbar
```

---

# 🔀 Pull Request

بعد رفع الفرع

قم بإنشاء Pull Request إلى Branch

```
develop
```

ولا تقم بعمل Merge بنفسك.

سيتم مراجعة الكود أولًا.

---

# 📋 Team Rules

- لا تعمل على Main.
- لا تعمل على Develop مباشرة.
- لكل طالب Branch خاص به.
- اسحب آخر تحديث قبل البدء.
- ارفع التعديلات باستمرار.
- إذا واجهت Merge Conflict لا تحاول حله عشوائيًا.
- اسأل المسؤول عند وجود مشكلة.
